# Canvas Pattern Components

Exposes Drupal Canvas patterns as first-class, reusable components, so a
centrally managed pattern stays the single source of truth instead of being
forked when placed.

## Why

Canvas's built-in approach to patterns can only copy the pattern into the page,
and changes to the pattern do not update existing instances. This module allows
page builders to place a pattern as a live reference, so that edits to the
pattern propagate to every layout that uses it.
